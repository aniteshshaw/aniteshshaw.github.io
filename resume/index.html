QA Technical Architect

Feb 2023 – Present

Logistics company, North America · remote

A large logistics business moving its core systems from legacy platforms to the cloud.

  • Lead a 30+ person QA organization across the US and India. I own test strategy and automation architecture, give hiring input, coach leads, and set the engineering standards every squad works to.
  • Built QIS, an AI agent workflow on GitHub Copilot and MCP. Its agents and reusable skills check stories for readiness, design test cases, write Playwright automation, review test PRs against six quality gates, attach evidence to work items, triage defects and run incident RCA. Squads picked it up on their own; analysis and design effort fell 60–70%, and it won an enterprise Technology Innovation Award.
  • Ran the AI adoption program around it: demos at All Hands and TechTrek, lunch-and-learns, a champion in each squad, and usage telemetry built on agent lifecycle hooks, so adoption figures came from real usage rather than surveys.
  • Designed governed self-healing for Playwright tests. A test can repair a moved or renamed element on its own, but a change that looks like a real defect goes to a person instead of being patched over.
  • Built a service dependency and readiness dashboard and shipped the first version in under a week. False defect reports dropped 70–75%, and each incident now takes 4–6 fewer hours to investigate.
  • Set up test data management from nothing: Python and PowerShell scripts that mask production-derived data and generate synthetic data, so squads can test safely without a vendor tool.
  • Brought real-user monitoring (Datadog RUM) into test design, so the paths customers actually use get tested first, with Core Web Vitals as pass/fail gates.
  • Led ETL testing for a finance-system migration to a cloud ERP, checking accuracy and consistency across every connected system.
  • Built an AI triage agent that summarizes new issues and suggests a probable root cause (internal AI hackathon winner), and a PowerShell installer that cut test-environment setup from about 25 minutes to 2–3.
  • Report defect trends and release readiness to leadership in Power BI. The program has held ~98% customer satisfaction through FY25–26 with zero escalations.
